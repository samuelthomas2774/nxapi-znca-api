nxapi f-generation API
---

nxapi-znca-api is used by nxapi and other applications that use the Nintendo Switch App's API, including game-specific services such as SplatNet 3 and NookLink, to authenticate to Nintendo's servers.

The f-generation API generates a value (known as `f`) normally generated by the Nintendo Switch App when you sign in with your Nintendo Account. To do this, it needs the Nintendo Account ID token the app uses to authenticate to it's own API (the API that nxapi and other applications use).

No other information is required by the Nintendo Switch App's API for authentication, so it is possible to access the API as your account with only this token. The ID token does not allow full access to your Nintendo Account however, and does not contain your sign-in ID, email address, or password. The token includes the following information:

- Your Nintendo Account ID
- Your Nintendo Account country
- Information about the token itself, such as when it expires

When accessing a game-specific service, the API is used to generate another `f` value, using the token the Nintendo Switch App uses to access it's API after authenticating using an ID token. This token includes the following information:

- Your Nintendo Switch App user ID
- Your Nintendo Switch Online membership status (either active or inactive)
- Your child restriction status (either 13+ or under 13)
- Information about the token itself, such as when it expires

Additionally, since June 2025, the Nintendo Switch App encrypts all data sent to/from the app using a non-standard algorithm. This means that **all data sent to or received from the Nintendo Switch App's API must be sent to the f-generation API** for encryption/decryption. This does not include game-specific services.

The f-generation API does not store Nintendo Account ID tokens or Nintendo Switch App tokens. The API does store the user identifier, either the Nintendo Account ID or the Nintendo Switch App user ID depending on the type of request, to prevent excessive and unnecessary requests from a single user, either due to malicious or misbehaving clients, as this would prevent other users from using the service. The API also stores request logs which include your network address and the User-Agent sent by the software used, which may contain limited information about your system.

The f-generation API is developed and run by [Ellie](https://github.com/ellie-gray). I do not maintain any software that uses this API other than nxapi; please contact the maintainers of the software you are using if you have any issues.
